## Bug hunt #1 — SQL injection
- Bug: The user input q is dropped directly into the SQL string using an f-string, which allows an attacker to inject malicious SQL commands.
- Why Claude wrote it: It copied a common older pattern where f-strings were used to build queries. The code looks clean and works normally so Claude did not flag it as dangerous.
- Fix: Use a parameterized query and pass q as a named parameter so the database driver handles escaping.

## Bug hunt #2 — hallucinated package
- Bug: flask_simpleauth does not exist. Claude invented a package name that sounds plausible but is not real.
- Why Claude wrote it: Claude pattern-matched on similar package names like Flask-Login and generated a convincing but fake import.
- Fix: Use the real package Flask-Login. The correct import is from flask_login import LoginManager, login_required.

## Bug hunt #3 — edge case
- Bug: Calling average_rating([]) causes a ZeroDivisionError because len([]) is 0.
- Why Claude wrote it: Claude only tested the happy path and did not consider an empty list as input.
- Fix: Add a guard that returns 0 or None if the list is empty before dividing.

## Bug hunt #4 — hardcoded secret
- Bug: The real API key is hardcoded in the source file. If committed to git it is exposed to anyone who can read the repo.
- Why Claude wrote it: Claude focused on making the code work and did not flag the security risk of a hardcoded credential.
- Fix: Load the key from an environment variable with os.environ.get and rotate the exposed key immediately.

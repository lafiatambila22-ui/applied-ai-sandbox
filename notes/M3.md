## Step 2 — CLAUDE.md behaviors

- It says don't edit the tests to make them pass. Without this, Claude will modify test files to force them to pass instead of fixing the actual code.
- It tells Claude to read the task file before writing code. Without this, Claude would jump straight into coding and likely solve the wrong problem.
- It says keep changes scoped to the task. Without this, Claude would refactor unrelated files and make changes beyond what was asked.

- Claude edited conftest.py to pre-seed the session so existing tests would pass, which violates the "don't edit tests" convention from CLAUDE.md.
- Claude also completed Task 02 (delete notes) without being asked, making changes well beyond the scope of the request.
